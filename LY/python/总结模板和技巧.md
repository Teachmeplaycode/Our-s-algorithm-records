## 1-3 哈希表

| 题号 | 题目 | 模式 | 核心技巧 |
|------|------|------|----------|
| 1 | 两数之和 | 哈希表一次遍历 | 对每个元素查 `target - num` 是否已在 map 中，再插入当前元素，避免自匹配 |
| 2 | 字母异位词分组 | 哈希表 + 规范化 key | 用 `sorted(s)` 作为字典 key，异位词排序后相同，自然归入同一桶 |
| 3 | 最长连续序列 | 哈希集合 | 放入 set，只从**序列起点**（`num-1` 不在 set 中）开始向后扩展，保证 O(n) |

**统一思想：** 哈希 O(1) 查找，避免嵌套循环。

## 4-7 双指针

| 题号 | 题目 | 模式 | 核心技巧 |
|------|------|------|----------|
| 4 | 移动零 | 快慢指针（同向） | 慢指针标记写入位置，快指针扫描，遇到非零就交换 |
| 5 | 盛水最多的容器 | 双指针从两端向中间收缩 | 永远移动**较矮**那一侧的指针，因为矮边是面积的瓶颈 |
| 6 | 三数之和 | 排序 + 固定一个 + 双指针 | 排序后固定 `i`，左右双指针找 `-nums[i]`，三层去重 |
| 7 | 接雨水 | 双指针 + 左右最大值 | 维护 `lm`/`rm`，处理**较小**一侧（该侧积水由自己的最大值决定） |

**模板：双指针从两端**
```python
l, r = 0, len(nums) - 1
while l < r:
    if 条件:
        # 处理
        l += 1
    else:
        r -= 1
```

## 8-9 滑动窗口

| 题号 | 题目 | 模式 | 核心技巧 |
|------|------|------|----------|
| 8 | 无重复字符的最长子串 | 滑动窗口 + set | 遇到重复就从左收缩（移除 `s[left]`），set 做 O(1) 去重判断 |
| 9 | 找到字符串所有字母异位词 | 定长滑动窗口 + 频率计数 | 维护 `count` 字典和 `req` 计数器（还需满足的字符数），`req == 0` 即找到 |

**模板：滑动窗口**
```python
left = 0
for right in range(len(s)):
    # 扩展右边界，更新窗口状态
    while 窗口不满足条件:
        # 收缩左边界，更新窗口状态
        left += 1
    # 此时 [left, right] 是合法窗口
```

## 10-12 子串

| 题号 | 题目 | 模式 | 核心技巧 |
|------|------|------|----------|
| 10 | 和为K的子数组 | 前缀和 + 哈希表 | 当前前缀和 `p`，查 `count[p-k]` 有多少个，map 初始化 `{0: 1}` |
| 11 | 滑动窗口最大值 | 单调递减双端队列 | 存索引，弹出超范围的队头 + 弹出比当前小的队尾，队头即窗口最大值 |
| 12 | 最小覆盖字串 | 滑动窗口 + valid 计数器 | `valid` 记录已满足的字符种类数，`valid == len(need)` 时窗口合法 |

**模板：前缀和 + 哈希**
```python
prefix = 0
count = {0: 1}
for num in nums:
    prefix += num
    ans += count.get(prefix - k, 0)
    count[prefix] = count.get(prefix, 0) + 1
```

**模板：单调队列**
```python
from collections import deque
dq = deque()
for i in range(len(nums)):
    while dq and dq[0] <= i - k:  # 弹出超范围
        dq.popleft()
    while dq and nums[dq[-1]] <= nums[i]:  # 维护递减
        dq.pop()
    dq.append(i)
    # dq[0] 就是当前窗口最大值的索引
```

## 13-17 普通数组

| 题号 | 题目 | 模式 | 核心技巧 |
|------|------|------|----------|
| 13 | 最大子数组和 | Kadane 算法（DP） | 每个位置：从当前重新开始 or 延续前面的子数组，取较大者 |
| 14 | 合并区间 | 排序 + 线性扫描 | 按起点排序，当前起点 <= 上一个终点则合并，否则新开区间 |
| 15 | 轮转数组 | 暴力旋转 / 三次翻转 | `pop()` + `insert(0, ...)` 或最优解：整体翻转 → 前k翻转 → 后半翻转 |
| 16 | 除自身以外数组的乘积 | 前缀积 + 后缀积 | 左到右算前缀积，右到左乘以后缀积，不用除法，O(1) 额外空间 |
| 17 | 缺失的第一个正数 | 原地哈希（数组当哈希表） | 把 `nums[i]` 放到 `nums[nums[i]-1]` 的位置，扫描第一个不在位的 |

**模板：Kadane 算法**
```python
cur = nums[0]
ans = nums[0]
for i in range(1, len(nums)):
    cur = max(nums[i], cur + nums[i])
    ans = max(ans, cur)
```

**模板：前缀积**
```python
ans = [1] * len(nums)
prefix = 1
for i in range(len(nums)):
    ans[i] = prefix
    prefix *= nums[i]
suffix = 1
for i in range(len(nums) - 1, -1, -1):
    ans[i] *= suffix
    suffix *= nums[i]
```

## 18-21 矩阵

| 题号 | 题目 | 模式 | 核心技巧 |
|------|------|------|----------|
| 18 | 矩阵置零 | 辅助集合标记 | 两遍扫描：第一遍记录含 0 的行/列，第二遍置零 |
| 19 | 螺旋矩阵 | 边界收缩模拟 | 维护 `top/bottom/left/right` 四个边界，逐层剥洋葱 |
| 20 | 旋转图像 | 转置 + 翻转 | 先沿对角线转置 `matrix[i][j] ↔ matrix[j][i]`，再每行翻转 |
| 21 | 搜索二维矩阵 | 逐行二分 / Z 字形搜索 | 从右上角出发：当前值大了往左走，小了往下走 |

**模板：螺旋矩阵**
```python
top, bottom, left, right = 0, m-1, 0, n-1
while top <= bottom and left <= right:
    for i in range(left, right+1): ...    # 上行
    for i in range(top+1, bottom+1): ...  # 右列
    if top < bottom:
        for i in range(right-1, left-1, -1): ...  # 下行
    if left < right:
        for i in range(bottom-1, top, -1): ...    # 左列
    top += 1; bottom -= 1; left += 1; right -= 1
```

## 22-35 链表

| 题号 | 题目 | 模式 | 核心技巧 |
|------|------|------|----------|
| 22 | 相交链表 | 双指针对齐长度 | 算两链表长度差，长的先走差值步，再同步走直到相遇 |
| 23 | 反转链表 | 三指针迭代（pre/cur/nxt） | 保存 `nxt = cur.next`，`cur.next = pre`，推进三个指针 |
| 24 | 回文链表 | 转数组对比 | 全部值放入列表，比较 `lst[i]` 和 `lst[-i-1]` |
| 25 | 环形链表 | 快慢指针（Floyd） | fast 走两步、slow 走一步，相遇即有环 |
| 26 | 环形链表2 | Floyd 两阶段 | 第一阶段找相遇点；第二阶段一个从 head、一个从相遇点同步走，再相遇即入口 |
| 27 | 合并两个有序链表 | 虚拟头 + 迭代归并 | 比较两链表头，小的接到尾部，最后接剩余 |
| 28 | 两数相加 | 遍历 + 进位 | 同步遍历两链表，累加到数组，再处理进位，构建新链表 |
| 29 | 删除倒数第N个节点 | 双指针间距（dummy） | fast 先走 n+1 步，然后 fast/slow 同步走，fast 到尾时 slow 在目标前一个 |
| 30 | 两两交换节点 | 值交换 | 不动指针，直接交换相邻节点的值 `p.val, p.next.val = p.next.val, p.val` |
| 31 | K个一组翻转 | 分组收集 + 反转 | 每 k 个节点收集到列表，反转后重连指针 |
| 32 | 随机链表复制 | 交错法（原地克隆） | 三步：插入副本节点 → 设 random → 拆分两个链表 |
| 33 | 排序链表 | 最小堆 | 全部节点入 `PriorityQueue`，依次弹出构建有序链表 |
| 34 | 合并K个升序链表 | 最小堆 | 同上，多链表所有节点入堆，弹出即有序 |
| 35 | LRU 缓存 | `OrderedDict` | `move_to_end` 更新访问顺序，`popitem(last=False)` 淘汰最久未用 |

**模板：反转链表**
```python
pre, cur = None, head
while cur:
    nxt = cur.next
    cur.next = pre
    pre = cur
    cur = nxt
return pre
```

**模板：快慢指针找环入口**
```python
slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow == fast:          # 第一阶段：相遇
        ptr = head
        while ptr != slow:    # 第二阶段：找入口
            ptr = ptr.next
            slow = slow.next
        return ptr
return None
```

## 36-50 二叉树

| 题号 | 题目 | 模式 | 核心技巧 |
|------|------|------|----------|
| 36 | 中序遍历 | 递归 DFS（左-根-右） | 闭包捕获外部列表收集结果 |
| 37 | 最大深度 | 递归 DFS | `max(dfs(left), dfs(right)) + 1` |
| 38 | 翻转二叉树 | BFS + 交换左右子树 | 队列层序遍历，每个节点交换 `left/right` |
| 39 | 对称二叉树 | 递归镜像比较 | `isMirror(l.left, r.right)` 且 `isMirror(l.right, r.left)` |
| 40 | 二叉树的直径 | 后序 DFS + 全局最大值 | 每个节点算 `left_depth + right_depth` 更新答案，返回 `max(l,r)+1` |
| 41 | 层序遍历 | BFS + 层大小控制 | `size = len(queue)` 每轮处理一层 |
| 42 | 有序数组转BST | 分治递归 | 取中间元素为根，左右子树递归构建 |
| 43 | 验证BST | DFS + 范围传播 | 传 `(min, max)` 上下界，每节点必须在界内 |
| 44 | BST第K小 | 中序遍历（有序性） | BST 中序遍历天然有序，第 k 个即答案 |
| 45 | 右视图 | BFS层序取最后一个 | 每层最后一个加入结果 |
| 46 | 展开为链表 | 前序遍历收集 + 重建 | 先前序收集所有值，再构建右偏链表 |
| 47 | 前序+中序建树 | 递归 + 索引切割 | `preorder[0]` 是根，在 `inorder` 中找到根的位置分割左右子树 |
| 48 | 路径总和III | 前缀和 + 哈希表（树上） | DFS 遍历，`cnt[prefix - target]` 计数，回溯时减回 |
| 49 | 最近公共祖先 | 后序 DFS（自底向上） | 左右子树分别返回非空则当前节点是 LCA |
| 50 | 最大路径和 | 后序 DFS + 全局最大值 | `max(0, dfs(left)) + max(0, dfs(right)) + val` 更新答案，返回单臂最大 |

**模板：后序 DFS 求树的直径/路径和**
```python
def dfs(node):
    if not node: return 0
    l = dfs(node.left)
    r = dfs(node.right)
    self.ans = max(self.ans, l + r + node.val)  # 经过当前节点的路径
    return max(l, r) + node.val                   # 返回给父节点的单臂值
```

**模板：树上前缀和**
```python
def dfs(node, prefix):
    if not node: return
    prefix += node.val
    self.ans += cnt[prefix - target]
    cnt[prefix] += 1
    dfs(node.left, prefix)
    dfs(node.right, prefix)
    cnt[prefix] -= 1   # 回溯！
```

## 51-54 图论

| 题号 | 题目 | 模式 | 核心技巧 |
|------|------|------|----------|
| 51 | 岛屿数量 | 多源独立 BFS | 遍历每个格子，遇到未访问的陆地就 BFS 汇总整座岛，计数+1 |
| 52 | 腐烂的橘子 | 多源同时 BFS | 所有腐烂橘子同时入队，**按层扩散**，`size = len(queue)` 控制每分钟 |

**模板：单源/多源独立 BFS（岛屿数量）**
```python
for i in range(m):
    for j in range(n):
        if grid[i][j] == '1' and not visited[i][j]:
            queue = [(i, j)]
            visited[i][j] = True
            while queue:
                x, y = queue.pop(0)
                for dx, dy in [[0,1],[0,-1],[1,0],[-1,0]]:
                    nx, ny = x+dx, y+dy
                    if 0<=nx<m and 0<=ny<n and grid[nx][ny]=='1' and not visited[nx][ny]:
                        visited[nx][ny] = True
                        queue.append((nx, ny))
            ans += 1  # 一座岛处理完
```

**模板：多源同时 BFS（腐烂的橘子）**
```python
queue = []
for i in range(m):
    for j in range(n):
        if grid[i][j] == 2:
            queue.append((i, j))

ans = 0
while queue:
    size = len(queue)
    rotted = False
    for _ in range(size):
        x, y = queue.pop(0)
        for dx, dy in [[-1,0],[1,0],[0,-1],[0,1]]:
            nx, ny = x+dx, y+dy
            if 0<=nx<m and 0<=ny<n and grid[nx][ny]==1:
                grid[nx][ny] = 2
                queue.append((nx, ny))
                rotted = True
    if rotted:
        ans += 1
```
