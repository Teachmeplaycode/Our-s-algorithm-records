# 双指针
快慢指针可以用于
1. 检测链表是否有环
快指针每次走两步，慢指针每次走一步。如果链表有环，快慢指针最终会在环内相遇；如果快指针到达null，则无环。
2. 找到环的入口节点
在快慢指针相遇后，将慢指针重置到头节点，然后两个指针都每次走一步，再次相遇的位置就是环的入口。
3. 寻找链表的中间节点
快指针走两步，慢指针走一步。当快指针到达末尾时，慢指针正好在中间（偶数长度时偏向中间偏右）。可用于归并排序链表等场景。
4. 判断回文链表
先用快慢指针找到链表中间，然后反转后半部分，再与前半部分逐一比较。
5. 寻找重复数（数组）
将数组值视为指向下一个索引的指针，形成类似链表的结构。用快慢指针找出重复的数字（环形入口）。
6. 删除链表的倒数第 n 个节点（变形）
快指针先走 n 步，然后快慢同时走，快指针到末尾时慢指针的下一个节点就是待删除节点（不过此用法不常见，更适合用双指针差 n 步，不是严格“快慢步长不同”）。

## 4.移动零
给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。请注意 ，必须在不复制数组的情况下原地对数组进行操作。

示例 1:
输入: nums = [0,1,0,3,12]
输出: [1,3,12,0,0]

示例 2:
输入: nums = [0]
输出: [0]
 
提示:
1 <= nums.length <= 104
-231 <= nums[i] <= 231 - 1
```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow,fast=0,0
        while fast < len(nums):
            if nums[fast] != 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1
            fast += 1
```
